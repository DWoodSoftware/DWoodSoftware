# `$ ./launch-challenge --target 10000`

I'm running a public software-building experiment:

> **Ship at least one new software product every week until the products collectively generate £10,000 in realised gross software revenue.**

Not £10k ARR.

Not £10k in theoretical valuation.

Not £10k worth of encouraging comments.

**£10,000 actually paid for software.**

The point is to repeatedly exercise the whole loop:

```text
problem
  ↓
build
  ↓
ship
  ↓
distribution
  ↓
feedback
  ↓
revenue?
  ├── yes → investigate further
  └── no  → learn something and ship again
```

The projects are deliberately small and fast.

They don't need the engineering standards of a long-lived platform.

They do need to work well enough to answer the question:

```text
Will anyone actually use this?
```

Preferably followed by:

```text
Will anyone pay for it?
```
